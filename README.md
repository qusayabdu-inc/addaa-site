# addaa-site (retired)

This repository used to publish addaa.io through GitHub Pages.

Since 14 Nov 2026 the website lives in the app repository, **qusayabdu-inc/Addaa.io → `/web`**. It is deployed by Cloudflare Workers (Worker `addaa-web`) to https://addaa.io.

The GitHub Pages workflow and the `CNAME` file were removed, so this repository no longer publishes anything. It is kept for history only and can be archived.
